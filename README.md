# Убойный хакатон: считаем состояния самых успешных акторов

Доклад для **HolyJS 2026 Autumn** про управление состоянием во фронтенде, оформленный как визуальная новелла по мотивам фильма «Такер и Дейл против зла».

Девять джунов проходят финальный этап собеседования — хакатон в загородном доме у двух тимлидов. Каждый джун со своим стейт-менеджером. К вечеру останется один — и победит не «самая модная библиотека», а модель, которую понял её владелец.

> **Мораль доклада:** убивает не библиотека, а отсутствие модели. Каждый из менеджеров мог спасти своего героя.

## Содержание доклада

### Зачин

Трейлер: «В финал после 20 этапов собеседований вышли девятеро претендентов. Но в конце останется ТОЛЬКО! ОДИН! …стейт-менеджер». Титульный экран с меню — как у настоящей новеллы.

### Сцена 0 — «Заправка»

Прохор даёт джунам напутствие, но Потап перебивает: «TAILWIND! Реакт, Vite v27.29.4 VIP Edition и Effector!» Ответ Прохора «По взаимному согласию — ради БЭМа» повергает джунов в ужас: слово из трёх букв. Прохор покупает коробку ромашкового чая. Запомните этот чай.

### Сцена 1 — «Озеро»

Девятеро вайбкодят прямо в озере — ноуты на надувных подлокотниках. У Алисы тонет ноутбук вместе с веткой («ветка утонула»). Прохор спасает и Алису, и ноутбук, бормоча «SSH-ключ был успешно установлен… а ещё есть такая интересная штука — PGP!». Студенты убегают — «лимиты обновились!» — и слышат вслед только обрывок: **«МЫ ВЗЯЛИ ВАШУ ПОДРУГУ…»** Первое событие без контекста.

### Сцена 2 — «Дом Кузьмы, разведка»

Повод — «показать навайбкоженное» (презентация так и не начнётся). Цель — спасти «захваченную» Алису. Митя заглядывает в окно: Алиса неподвижна лицом в код, Прохор колдует над её ноутбуком, две чашки, пар. Здесь — первая пара код-примеров: **Василиса** (useState, пять булевых флагов → `'KIDNAPPING'`) против **Алисы** (XState, 2 секунды наблюдения → «ревью и ромашка»). Митя гибнет первым: Кузьма мирно пилил дрова, задел бензопилой улей — Митя бежал, не глядя (useReducer без guard'а на проверку пути).

### Каскад — «Операция "Освобождение"»

Каждая попытка спасти Алису убивает спасателя — и каждый раз это классический баг соответствующего менеджера:

| # | Погибший | Менеджер | Что убило |
|---|---|---|---|
| 1 | Митя | `useReducer` | переход без guard'а — «бежал не глядя» |
| 2 | Толя | `Redux` | race condition: координаты цели устарели к броску |
| 3 | Михаил | `Zustand` | «отмена прошла», но таймер никто не отменил |
| 4 | Чеслав | `Recoil` | мёртвая зависимость: npm молчит, React 19 — нет |
| 5 | Яша | `MobX` | каскад reactions без disposer'ов |
| 6 | Василиса | `useState` | бросок канистры до завершения async-проверки |
| 7 | Нина | `Jotai` | цикл «мнение ⇄ угроза» — тихий бесконечный пересчёт |
| 8 | Потап | `Effector` | хрупкая сеть из шести узлов: ромашковый чай → аллергия → ингалятор не найден |

Параллельно приезжает **Гурий** — сеньор-QA в ковбойской шляпе: его юнит-тест на моках «не воспроизводит» баг (в песочнице контекст всегда на месте), и он гибнет под упавшим stack trace. Флешбек объясняет паранойю Потапа: отец писал на jQuery+БЭМ и выгорел на легаси.

### Финал — «Ромашковый чай»

Ружьё из сцены 0 стреляет: Прохор, не глядя, бросает в Потапа коробку ромашкового чая. Одна и та же XState-машина с разным контекстом даёт два исхода: Алиса (`isAllergic: false`) спокойно пьёт чай, Потап (`isAllergic: true`, ингалятор у дровокола) падает из окна. **«Выживает та модель, которую понял».**

### Победа

Алиса получает оффер — её машина единственная доехала до демо без фатальных багов. Честный финальный слайд: «убивает не библиотека, а отсутствие модели» — таблица, как каждый менеджер спас бы своего героя, включая строку для XState («забытый `isAllergic` в контексте убивает и Алису» — не серебряная пуля). Перевязанный Кузьм подводит итог: «Product Manager, we have had a doozy of a sprint!»

### Backstage

После «Спасибо!» — бесконечный цикл фотографий со «съёмочной площадки»: бензопила — пенопласт, пчёлы — плюш, все «погибшие» живы, а в режиссёрском кресле написано STATE MACHINE.

## Как смотреть

Дека — [reveal.js](https://revealjs.com) 6.0.2 (форк) со слоем визуальной новеллы: спрайты персонажей с эмоциями, диалоговые окна, эффект тайпрайтера.

```bash
npm install
npm start          # http://localhost:8000
```

- **`index.html`** — основной вариант: VN-сцены внутри канваса 1280×720, текст печатается посимвольно.
- **`hud.html`** — вариант B: та же история, но VN-сцена закреплена на реальном вьюпорте (вне масштабирования канваса).
- Стрелки — навигация, `S` — заметки спикера, URL-хэш — прямые ссылки на слайды.

## Структура репозитория

Кастомное (сама лекция):

- `index.html`, `hud.html` — обе вариации деки, синхронные;
- `css/vn.css`, `css/vn-hud.css` — компоненты визуальной новеллы (BEM `vn__*`);
- `js/vn-typewriter.js` — эффект печатающегося текста;
- `dist/image/` — сгенерированный арт: фоны, спрайты персонажей по эмоциям (`<имя>/<имя>-<эмоция>.png`), эффекты-объекты, backstage-кадры.

Всё остальное (`js/`, `plugin/`, `css/theme/`, `test/`, `react/`, `examples/`) — стоковый reveal.js. Слайды сознательно едят закоммиченный билд `dist/` — после правок ядра/тем запускайте `npm run build`.
